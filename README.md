# Customer 360 — Repeat Purchase Prediction

## Project Overview

Customer 360 is a machine learning project that predicts whether a customer is likely to make a repeat purchase.

The main idea is to take a customer's previous purchasing behavior, convert it into useful features, and use a trained machine learning model to predict the probability of a future repeat purchase.

The project also includes a simple Streamlit web application, automated testing, prediction logging, monitoring, and GitHub Actions.

---

## Project Goals

The project was built to cover the complete machine learning workflow:

* Prepare and transform customer transaction data
* Create customer-level behavioral features
* Train a repeat-purchase prediction model
* Save and reuse the trained model
* Validate the model using an independent test set
* Build a web application for making predictions
* Log predictions for monitoring
* Add automated tests
* Use GitHub Actions to run tests automatically
* Deploy the application using Streamlit Cloud

## Model

The project uses a saved Scikit-learn model:

```text
repeat_purchase_model_v2.pkl
```

Model version:

```text
v2.0
```

The model expects 8 customer behavioral features:

1. `recency_days`
2. `frequency`
3. `total_items`
4. `total_revenue`
5. `average_transaction_value`
6. `unique_products`
7. `return_count`
8. `lifetime_days`

The feature definition and model version are stored separately in:

```text
feature_schema.json
model_metadata.json
```

This helps make sure that the application uses the same feature names and order expected by the trained model.

---

## Feature Description

| Feature                     | Description                                                   |
| --------------------------- | ------------------------------------------------------------- |
| `recency_days`              | Number of days since the customer's most recent purchase      |
| `frequency`                 | Number of transactions made by the customer                   |
| `total_items`               | Total number of items purchased                               |
| `total_revenue`             | Total revenue generated by the customer                       |
| `average_transaction_value` | Average value of the customer's transactions                  |
| `unique_products`           | Number of different products purchased                        |
| `return_count`              | Number of returned items/transactions                         |
| `lifetime_days`             | Number of days between the customer's first and last purchase |

These features summarize the customer's purchasing behavior and are used as input to the prediction model.

## Dataset

The project is based on the **Online Retail II** transaction dataset.

The original transaction data contains information such as:

* Invoice number
* Product code
* Product description
* Quantity
* Invoice date
* Unit price
* Customer ID
* Country

The raw transaction-level data is transformed into customer-level features before being passed to the model.

## Independent Model Testing

The model was tested using a separate test set rather than using the same data used for training.

The independent test set contains:

```text
1,070 samples
8 features
```

The test data was loaded separately and used to verify that the saved model could make predictions correctly.

The test process also checks:

* Feature names
* Feature order
* Missing values
* Prediction values
* Prediction probabilities
* Model loading
* Model fitting

Automated tests are implemented in:

The test suite checks that:

* The model file exists

## GitHub Actions

The project uses GitHub Actions for continuous integration.

```text

```

Whenever changes are pushed to the `main` branch, GitHub Actions automatically:

```text
Checkout repository
        ↓
Set up Python
        ↓
Install dependencies
        ↓
Run pytest
```

The first workflow run completed successfully.

This helps catch problems in the project before they affect the deployed application.

## Streamlit Application

The web application is implemented in:

```text
app.py
```

The application allows a user to enter the eight customer behavioral features and receive a prediction.

The application displays:

* Model information
* Model version
* Expected features
* Prediction result
* Repeat purchase probability
* A simple business recommendation
* Prediction history

Example prediction output:

```text
Customer is predicted NOT to make a repeat purchase.

Repeat Purchase Probability:
36.81%
```

The exact prediction depends on the input values entered by the user.

---

## Prediction Logging

Every prediction made through the Streamlit application is logged in an SQLite database.

The application records information such as:

* Prediction
* Repeat purchase probability
* Model name
* Model version
* Feature values
* Timestamp

After a prediction is successfully saved, the application displays:

```text
Prediction successfully logged to database.
```

The application also displays the number of predictions that have been logged.

---

## Monitoring

Basic model monitoring is implemented in:

```text
monitoring.py
```

The monitoring script can report:

* Total number of predictions
* Number of predicted repeat purchases
* Number of predicted non-repeat purchases
* Predicted repeat-purchase rate
* Average prediction probability
* Minimum probability
* Maximum probability
* Model names used
* Model versions used
* Recent predictions

If no prediction database exists yet, the monitoring script exits gracefully and explains that predictions need to be made through the application first.

## Deployment

The Streamlit application is deployed using Streamlit Cloud.

The deployed application allows users to interact with the trained model without needing to run the Python code locally.

The application loads:

```text
repeat_purchase_model_v2.pkl
model_metadata.json
feature_schema.json
```

and uses them to perform predictions.

## Running the Project Locally

Clone the repository and install the required packages:

```bash
git clone https://github.com/Aymanhb1/Customer_360.git
cd Customer_360
```

Install the dependencies:

```bash
pip install -r requirements.txt
```

Run the Streamlit application:

```bash
streamlit run app.py
```

The application can then be opened in the browser.

---

## Running the Tests

To run the automated tests locally:

```bash
pytest -v
```

The tests should verify that the saved model and its expected feature schema are working correctly.
